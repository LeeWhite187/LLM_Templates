If a design chat has generated an implementation guide from its R0 version.
And, the chat is now seeing the R1 implementation guide, here's the differences that the chat may need to be aware of, for migrating existing content:

Here are notes about what changed in the implementation guide from R0 (used) to R1 (current).
Two convention texts updated in the implementation guide template.
1. The "Forward-looking reference" convention no longer claims "historical context lives in the spec and its revision log" (since neither has one) — it now points at Git for both.
2. The "No revision log" convention reframed to acknowledge this is now a universal rule across specs and guides, not a guide-specific stance.
